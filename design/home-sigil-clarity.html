Home sigil, sharper rings and nodes

The Market read sigil is drawn at 760px from a 1040-unit viewBox, so every 1px hairline renders at 0.73px and smears into grey haze, and each node is a 7px diamond turning at odd angles. Proposed: hairlines stay one screen pixel, nodes are 10px and stay upright while they orbit, and white strokes are 1.6× brighter for this instance only. Arc, tip, colours, speeds, scrim, mask and layout are unchanged. Real app CSS and markup; all values are mock design data.

What changes

  1. Hairlines stay 1 screen px. Rings, ticks, nodes, orbits and the seal get vector-effect="non-scaling-stroke", so the 0.73× scale no longer thins them below a pixel.
  2. Nodes 10px and upright. Diamond half-size 5 → 7 viewBox units. Each node counter-spins against its group, so it still orbits but stays a crisp ◇ like the logo.
  3. White strokes ×1.6. Uses the existing strokeBoost: minor ticks .11 → .18, mid .20 → .32, major .38 → .61, nodes .34 → .54.
  4. Home only. A new crisp option, off by default: Sign-in, ambient, welcome, seal and dial render exactly as today.

Unchanged

  • The arc, tip, price line, colours, glow and breathing.
  • Rotation speeds (300s ticks, 198s nodes for Favorable) and the stance-change entrance.
  • Scrim, radial mask, the frosted stats row and why-bar (still blurred by design), and the 760px size at 72% / 50%.
  • Reduced motion and lite mode: still no motion.

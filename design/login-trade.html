The artwork: Candle Light

Original to Dispel, not borrowed from Raycast.

design/assets/dispel-hero.svg · 6 KB

Raycast uses diagonal bars of light. Dispel uses a run of rising candlesticks tilted 28°. Up candles are warm (amber → coral → rose) and down candles are cool (periwinkle → cobalt → deep space). The whole run is blurred into haze, with a crisp copy masked into the centre. The noise clears where you look, which is what the name promises.

It is one deterministic SVG (6 KB, generated by design/assets/generate-hero.mjs) that scales to any window without pixelation. Sign-in uses it full-bleed with a slow 38-second drift. Trade uses the same file as a blurred ambient glow at 22% opacity behind the top right, so the terminal isn't flat black but no chart data ever sits on colour.
